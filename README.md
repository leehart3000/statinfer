# statinfer

Statistical inference for modern JavaScript and TypeScript.

## Roadmap

### v0.1 (in progress)
- `tTest`: one-sample, paired, two-sample (Welch and pooled)
- `proportionTest`: one- and two-sample z-tests
- `chiSquareTest`: independence and goodness-of-fit
- `correlationTest`: Pearson and Spearman
- `anova`: one-way ANOVA
- `fishersExactTest`: 2×2 tables

### Stretch goals
- `wilcoxonTest`: rank-sum and signed-rank
- `kruskalWallisTest`

### v0.2
- `linearRegression`
- Tukey HSD post-hoc tests for `anova`
