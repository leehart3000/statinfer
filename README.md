# statinfer

[![CI](https://github.com/leehart3000/statinfer/actions/workflows/ci.yml/badge.svg)](https://github.com/leehart3000/statinfer/actions/workflows/ci.yml)

Statistical inference for modern JavaScript and TypeScript.

statinfer provides classic hypothesis tests with one consistent result format, full TypeScript types, and results checked against SciPy and statsmodels. It has no runtime dependencies, and bundlers only include the tests you import.

## Install

```sh
npm install statinfer
```

Requires Node.js 22 or newer.

## Quick start

```ts
import { tTest, summarize } from "statinfer";

const result = tTest({ x: [5.1, 4.9, 5.6, 5.8, 6.0, 5.5, 5.3, 6.2], mu: 5 });
console.log(summarize(result));
```

## Tests

| Function | What it tests |
| --- | --- |
| `tTest` | Means: one-sample, paired, or two-sample (Welch by default, or pooled) |
| `proportionTest` | Proportions: one-sample, or the difference between two |
| `chiSquareTest` | Tables of counts: independence, or goodness-of-fit |
| `correlationTest` | Association: Pearson or Spearman |
| `anova` | Means of three or more groups (one-way) |
| `fishersExactTest` | 2×2 tables, including small counts |

Every test takes a single options object and returns a `TestResult`:

| Field | Meaning |
| --- | --- |
| `method` | The name of the test |
| `statistic` | The test statistic (t, z, chi-square, F, …) |
| `pValue` | The p-value |
| `df` | Degrees of freedom: a number, a pair, or `null` |
| `estimate` | The estimated effect, or `null` |
| `confidenceInterval` | `[lower, upper]`, or `null` |
| `confidenceLevel` | For example `0.95`, or `null` |
| `alternative` | `"two-sided"`, `"less"`, `"greater"`, or `null` |

Fields that don't apply to a test are `null`, so every result has the same shape. One-sided tests can have an infinite interval end; note that `JSON.stringify` saves `Infinity` as `null`.

## Accuracy

Every test is checked against SciPy or statsmodels to about 10 decimal places. The reference values live in [`test/fixtures`](https://github.com/leehart3000/statinfer/tree/main/test/fixtures) and are generated by [`scripts/generate_fixtures.py`](https://github.com/leehart3000/statinfer/blob/main/scripts/generate_fixtures.py).

## Roadmap

### v0.1
- `tTest`, `proportionTest`, `chiSquareTest`, `correlationTest`, `anova`, `fishersExactTest`
- `summarize` for readable output

### Stretch goals
- `wilcoxonTest`: rank-sum and signed-rank
- `kruskalWallisTest`

### v0.2
- `linearRegression`
- Tukey HSD post-hoc tests for `anova`
- Conditional odds ratio and exact confidence interval for `fishersExactTest`
- Wilson confidence intervals for `proportionTest`
