# t-test demo

[statinfer](https://www.npmjs.com/package/statinfer) is a JavaScript package for statistical tests, with TypeScript types included. It runs in Node.js and in the browser.

This page demonstrates its `tTest` function. Enter your own numbers below, and statinfer calculates the result right here in your browser, explains what it means, and shows the JavaScript code that produces it.
