## When to use ANOVA

A one-way **ANOVA** (analysis of variance) asks whether **three or more groups have the same average**. For example: do three fertilisers give the same average plant height, or do students taught with four different methods get the same average score? For just two groups, use the [t-test](/t-test) instead.

It works by comparing two kinds of variation: how far apart the group averages are (**between** groups), and how spread out the values are inside each group (**within** groups). If the averages are far apart compared with the spread inside each group, the groups probably differ.

ANOVA works best when the values are independent, roughly bell-shaped within each group, and similarly spread out in every group. For skewed data or outliers, the Kruskal-Wallis test is more reliable, and it's planned for a future version of statinfer.

A significant result tells you that **at least one** group's average differs, but not which one. Follow-up ("post-hoc") tests such as Tukey's HSD answer that, and are also planned.

The **statistic** is the F statistic: the between-group variation divided by the within-group variation. The larger it is, the more the group averages differ relative to the spread inside each group. An ANOVA has two **degrees of freedom**: the first comes from the number of groups, and the second from the total number of values.

### The raw result

`anova` returns a plain JavaScript object, which your code can use directly. For example, `result.pValue` is the p-value, and `result.df` is a pair of numbers, `[between, within]`. Below, the same object is shown as **JSON** (JavaScript Object Notation), a standard text format for data, which you can save or send to other programs. ANOVA has no estimate, confidence interval or direction, so those fields are `null`.
