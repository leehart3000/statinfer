# Security policy

## Supported versions

Security fixes are made for the latest release only.

## Reporting a vulnerability

Please **don't** report security problems in public issues.

Instead, use GitHub's private vulnerability reporting: go to the repository's **Security** tab and click **Report a vulnerability**. Only the maintainers can see the report.

Please include a description of the problem, steps to reproduce it, and the version affected. You'll get a reply as soon as possible, on a best-effort basis.
